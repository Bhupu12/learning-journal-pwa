About Me

Hello, my name is Bhupendra Thapa. I am a student studying BSc (Hons) Computer Science and currently undertaking the Mobile Application Development module at the University for the Creative Arts (UCA).

I have a strong interest in web and application development, particularly in building interactive and user-friendly applications. This Learning Journal website was created to document my academic progress, reflect on weekly learning outcomes, and demonstrate my understanding of modern web technologies.

The project has been developed using HTML and CSS for structure and design, Vanilla JavaScript for interactivity, and a Flask backend to manage data storage and server-side logic. It is implemented as a Progressive Web Application (PWA), supporting offline functionality through a Service Worker.

In addition to the core Learning Journal, I extended the application with a mini-project feature to enhance usability and functionality. This allowed me to practise full CRUD operations, problem-solving, and frontend–backend integration in a real-world context.

Overall, this project represents my learning journey, technical development, and growing confidence in building complete web applications. In the future, I aim to further improve my skills by exploring advanced features such as data visualisation, authentication, and performance optimisation.
