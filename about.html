Hello, my name is Bhupendra Thapa. I am a BSc (Hons) Computer Science student and I completed this Learning Journal as part of my Mobile Application Development module. This website documents my learning progress, weekly reflections, and technical development throughout the module.

I have a strong interest in web and application development, particularly in designing interactive and user-friendly applications. The purpose of this Learning Journal is to demonstrate my understanding of modern web technologies while presenting my reflective learning journey in a structured format.

The project was developed using HTML and CSS for structure and visual design, Vanilla JavaScript for interactivity, and a Flask backend for server-side storage and functionality. It is implemented as a Progressive Web Application (PWA), with offline support provided through a Service Worker.

In addition to the core journal features, I extended the application with a mini-project feature to enhance usability and functionality. This helped me practise full CRUD operations, problem-solving, and frontend–backend integration in a realistic development environment.

Overall, this project represents my learning journey and growing confidence in building complete web applications. In the future, I would like to enhance the project further by implementing features such as user authentication, data visualisation, and performance optimisation.
