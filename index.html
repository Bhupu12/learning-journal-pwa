About Bhupendra

I am a BSc (Hons) Computer Science student with a strong interest in web and application development. This Learning Journal was created as part of my Mobile Application Development module to record my learning progress and demonstrate practical technical skills.

The application is developed as a Progressive Web App (PWA) using HTML and CSS for structure and visual design, Vanilla JavaScript for interactivity, and a Flask backend for managing data storage and server communication. Reflections are stored using server-side JSON, allowing full CRUD functionality including creating, editing, deleting, and searching entries.

A key focus of this project was usability and reliability. Offline functionality is supported through a Service Worker, ensuring the application remains accessible even without an internet connection. The user interface was carefully designed to be clear, responsive, and easy to navigate across different devices.

In addition to the core Learning Journal, I extended the application with a mini-project feature to enhance functionality and user engagement. This extension allowed me to practise problem-solving skills and gain a deeper understanding of frontend–backend integration in a real-world development environment.

Overall, this project reflects my technical development and growing confidence in building complete web applications. With more time, I would further improve the project by adding features such as data visualisation, user authentication, and performance optimisation.
