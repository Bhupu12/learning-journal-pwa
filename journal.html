Week 5 – Python & JSON Backend Integration

1. How is storing data in a JSON file different from using browser storage?
Storing data in a JSON file involves saving information on the server or local file system, making it persistent beyond the browser's scope. This approach enables sharing and backup of data, useful for collaborative or offline scenarios. In contrast, browser storage mechanisms like localStorage are limited to the client’s browser environment and are domain-specific, meaning the data cannot be accessed across different devices or browsers. JSON-based storage decouples data from the front end and supports long-term accessibility.

2. How did you use Python to create or update your JSON file?
I developed a Python script named save_entry.py which prompts the user for reflection input. The script reads from an existing reflections.json file, parses its content into a Python list, appends the new reflection along with metadata like the date and time using the datetime module, and then serializes the updated list back to the JSON file. This method leverages Python's json module for seamless conversion between Python objects and JSON format, promoting human-readable and structured data handling.

3. What does your PWA show locally, and what will users see on GitHub? Are they the same?
Locally, my Progressive Web App (PWA) uses JavaScript's fetch API to retrieve data from the reflections.json file and dynamically renders it into the DOM. This real-time interaction reflects any new entries added via Python. However, GitHub only displays the last pushed version of the JSON file since it's a static repository. To keep the GitHub version updated, manual commits are required. Therefore, what users see online may not always match what I see locally unless changes are regularly committed and pushed to the repository.

4. What extra feature did you add to your PWA using the JSON file, and why?
To enhance the functionality of my Learning Journal, I implemented two additional features: a reflection counter and an export button. The counter dynamically displays the total number of reflections fetched from the JSON file, offering immediate insight into the user’s progress. The export feature enables users to download the JSON file containing their reflections, promoting portability and data backup. Both features utilize DOM manipulation and event handling in JavaScript to interact with the JSON data structure effectively.
